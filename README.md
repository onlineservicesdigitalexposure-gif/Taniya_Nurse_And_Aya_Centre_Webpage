# Taniya Nurse & Aya Centre — Official Website

Official web application for **Taniya Nurse & Aya Centre**, providing compassionate home care, patient nursing, aya attendance, newborn baby care, and cooking support in Chak Garia near Baghajatin Railway Station, Kolkata 700075.

## 🚀 Technology Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling**: [Vite 8](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Forms**: [React Hook Form](https://react-hook-form.com/)
- **Linter**: [Oxlint](https://oxc.rs/)

## 🛠️ Project Scripts

```bash
# Start local development server
npm run dev

# Compile TypeScript and generate production build in /dist
npm run build

# Run high-performance linter
npm run lint

# Preview production build locally
npm run preview
```
